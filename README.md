# Erfan Hassanpur — Portfolio

Personal portfolio for an independent horror game developer. Work index with build notes, dated log, about, contact. Bilingual (EN/FA with RTL).

## Stack

- Hand-written HTML, CSS, vanilla JS. No framework, no build step, no tracking.
- Fonts: Fraunces (display), Space Grotesk (body), Vazirmatn (Persian), JetBrains Mono (labels).

## Run

Open `index.html`, or serve the folder (needed for the language toggle to persist via localStorage in some browsers):


## Edit

- Project entries + log: `PROJECTS` and `LOG` arrays in `script.js` (each has `en`/`fa` fields).
- Copy strings: `STR` object in `script.js`.
- Styles/tokens: `:root` block at top of `style.css`.

## Deploy

Static host. Netlify: drag & drop the folder. Vercel / GitHub Pages likewise.
